# Reality Vehicle Lab Developer Sync

This branch is the deployment branch for the local Reality Vehicle Lab.

- Branch: `chatgpt-dev`
- Local updater: Reality Vehicle Lab v0.2.0+
- Update manifest: `.rvl-update.json`
- Deployable paths: only resources listed in the manifest
- Current built-in vehicle diagnostics: `/checkhydro`, `/sethydro`, `/moddump`

Future ChatGPT changes intended for the local test server should be committed to this branch, then applied from the Lab dashboard with **Pull & Apply**.
